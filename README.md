# 업무시간 기록기 (TimeTracker)

부팅 시 자동 실행되어 출근/퇴근 및 실 업무시간(잠금·화면보호기 제외)을
자동으로 기록하고, 일일/주간 현황을 보여주는 윈도우 트레이 프로그램.

## 요구사항 매핑

| # | 요구사항 | 구현 |
|---|----------|------|
| 1 | 부팅 시 자동 시작 | `HKCU\...\Run` 레지스트리 등록 (`install_autostart.py`) |
| 2 | 시작 시 출근시간 기록 | 실행 즉시 `clock_in` 이벤트 기록 |
| 3 | 잠금(Win+L)/화면보호기/자리비움 시 카운팅 중지 | 세션 잠금 이벤트 + 화면보호기 폴링 + 자리비움(3분) 감지 → `stop` |
| 4 | 잠금 해제/복귀 시 카운팅 재개 | 잠금해제 이벤트 / 입력 재개 감지 → `start` |
| 5 | 퇴근 기록 (노트북 종료) | **아래 "퇴근 기록 방식" 참고** |
| 6 | 일일/주간 현황 | `report.py` + 트레이 메뉴 "현황 보기" |

## 설치

1. (이미 완료) Python 3.13 설치 확인
2. 폴더에서 **`setup.bat` 더블클릭**
   - 필요한 패키지 설치(pywin32, pystray, pillow)
   - 부팅 시 자동 시작 등록
   - 즉시 실행 (트레이에 시계 아이콘)

> 데이터는 OneDrive 동기화 충돌을 피하려고
> `%LOCALAPPDATA%\TimeTracker\time_tracker.db` (SQLite)에 저장됩니다.

## 사용

- **트레이 아이콘에 마우스 올리기**: 툴팁으로 현재 상태 + 오늘/이번 주 시간 (클릭 불필요, 약 2초마다 갱신)
- **트레이 아이콘 더블클릭** 또는 우클릭 → **현황 보기**: GUI 대시보드 창
  (오늘 실 업무시간, 출근/최근활동/체류시간, 주간 막대그래프, 합계·평균. 5초마다 자동 새로고침)
- 우클릭 → **현재 상태 알림**: 풍선 알림
- 우클릭 → **수동 일시정지**: 자리 비울 때 수동으로 카운팅 정지/재개
- 우클릭 → **퇴근 처리 후 종료**: 명시적 퇴근 기록 후 프로그램 종료
- 명령줄(텍스트) 확인도 가능:
  ```
  py dashboard.py              # GUI 대시보드 직접 실행
  py report.py                 # 텍스트 요약 (오늘 + 이번 주)
  py report.py --date 2026-06-20
  ```

## 퇴근 기록 방식 (요구사항 5) — 제안

노트북을 그냥 끄고 가도 퇴근시간이 정확히 남도록 **3중 안전장치**로 구현했습니다.

1. **정상 종료/로그오프 감지 (기본·권장)**
   윈도우가 종료/로그오프될 때 보내는 `WM_ENDSESSION` 메시지를 받아
   그 순간을 `clock_out`(퇴근)으로 기록합니다.
   → **시작 메뉴 → 전원 → 시스템 종료** 로 끄면 자동으로 정확히 기록됩니다.

2. **하트비트 기반 복구 (전원 강제 차단 대비)**
   업무 중일 때 30초마다 "마지막 활동 시각"을 저장합니다.
   배터리 방전·강제 전원오프처럼 종료 메시지를 못 남기고 꺼져도,
   **다음 날 켜질 때** 마지막 활동 시각을 그 날의 퇴근시간으로 자동 복구합니다.
   (오차 최대 30초)

3. **수동 퇴근 (가장 확실)**
   트레이 메뉴 **"퇴근 처리 후 종료"** 를 누르면 즉시 퇴근 기록 후 종료.

> **추천 사용법**: 평소엔 그냥 **시스템 종료**(1번)로 끄면 충분합니다.
> 노트북을 덮어 절전(Sleep)만 하고 가는 경우엔 그 시점이 마지막 활동으로 남으므로,
> 확실히 하려면 퇴근 시 2번(자동 복구)이 받쳐주고, 원하면 3번을 쓰면 됩니다.

## 자동 시작 관리

```
py install_autostart.py            # 등록
py install_autostart.py --status   # 등록 상태 확인
py install_autostart.py --remove   # 등록 해제
```

## 파일 구성

- `time_tracker.pyw` — 트레이 앱 본체(세션 감지·기록·하트비트·툴팁)
- `storage.py` — SQLite 저장 및 업무시간 계산(자정 분할·복구 포함)
- `dashboard.py` — GUI 현황 대시보드(tkinter)
- `report.py` — 일일/주간 현황 텍스트 출력
- `install_autostart.py` — 자동 시작 등록/해제
- `setup.bat` — 원클릭 설치
- `requirements.txt` — 의존 패키지

## 동작 원리 (업무시간 계산)

`clock_in`/`unlock`/입력복귀(start) ~ `lock`/`screensaver`/`idle`/`clock_out`(stop)
구간의 합이 실 업무시간입니다. 자정을 넘기는 구간은 날짜별로 분할 집계하며,
주간 합계는 해당 주(월~일) 기준으로 계산합니다.

**자리비움(idle) 감지**: 키보드·마우스 입력이 **3분(180초)** 이상 없으면 자동으로
일시정지하고, 다시 입력이 들어오면 즉시 재개합니다. (감지 주기 2초)
임계값은 `time_tracker.pyw` 상단의 `IDLE_THRESHOLD_SEC` 값으로 조정할 수 있습니다.
